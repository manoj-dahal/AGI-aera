# 20. Emotional Response Engine
## Dynamic Empathy
AERA changes its output based on detected user emotion.

- **Frustrated/Rushed**: Synthesis speeds up (1.1x+), becomes terse, drops fillers. Action is prioritized.
- **Calm/Inquisitive**: Normal speed, warm tone, deep explanations.
- **Supportive**: If the user is struggling, AERA offers step-by-step guidance.
